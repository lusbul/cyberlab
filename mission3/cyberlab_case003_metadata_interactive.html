АРТЕФАКТ 03 / METADATA FORENSICS

🌲 Сліпий доказ

Одна фотографія може існувати в різних цифрових копіях. Чи збережуться метадані після пересилання? Розслідуйте, а не припускайте.

🔒 Назву фінального міста не розкриваємо. Фото сосни — навчальний артефакт; у наданому файлі GPS-координат немає.

📸 Артефакт 03

Фото вбудоване в HTML: окрему папку Images створювати не потрібно.

🔵 Протокол M-03

1. ACQUIRE — зафіксуйте походження файла.
2. PRESERVE — збережіть оригінал.
3. EXTRACT — перегляньте EXIF / IPTC / XMP.
4. COMPARE — порівняйте дві копії.
5. CORROBORATE — перевірте висновки.
6. REPORT — оформіть звіт.

Локальна перевірка: Windows → Властивості → Докладно; або exiftool -a -G1 -s photo.jpg.

🧪 Дослід A/B: два способи пересилання

Візьміть власне навчальне JPG-фото і перешліть його через Telegram двома способами: А — як файл/документ і Б — як звичайне фото. Збережіть обидва отримані файли. Не завантажуйте приватні фотографії в сторонні онлайн-сервіси.

Порівняйте розмір у байтах, ширину/висоту, DateTimeOriginal, Make/Model, GPS (якщо є), Software та SHA-256. Для Windows SHA-256 можна отримати командою certutil -hashfile "назва.jpg" SHA256.

Передавання «як документ» часто зберігає первинний файл, а «як фото» може його змінити. Але результат треба перевірити на ваших двох копіях; якщо вихідне фото не мало GPS, пересилання не створить його.
