🧬 Практика 04
Куди зникають метадані?

Ви — цифровий криміналіст. Проведіть контрольований експеримент із фотографією: оригінал → аналіз → Telegram → повторний аналіз → висновок.

⏱️ 15–25 хв🔒 Обробка файлів у вашому браузері📋 Звіт TXT
🔐 Правило приватності. Обирайте навчальне фото без чутливої інформації. GPS-координати можуть розкривати місце зйомки. Ця сторінка аналізує файли локально, без надсилання на сервер. Не публікуйте оригінал із координатами у відкритих чатах.
НАВЧАЛЬНИЙ АРТЕФАКТ

📷 Завантажте фото для експерименту

Спробуйте навчальний файл PXL_20260803_042802653.jpg. Завантажте його як файл, не через попередній перегляд Telegram.

📥 Завантажити фотографію (JPG)

⚠️ Важлива перевірка: у доступній копії цього JPG EXIF-поля відсутні. Це дозволяє дослідити відсутність метаданих, але не доводить, що їх видалив Telegram. Щоб побачити зникнення EXIF, візьміть інший оригінал із підтвердженими EXIF-даними (наприклад, фото з власного телефона, скопійоване через USB).

КРОК 01 / ОРИГІНАЛ

📥 Візьміть вихідну фотографію

Завантажте на комп'ютер оригінальний JPG із камери (через USB або іншим способом без оброблення). Якщо викладач надав навчальний JPG, використайте його. Не зберігайте картинку зі сторінки браузера як заміну оригіналу.

КРОК 02 / WINDOWS

💻 Перевірте властивості файлу

Відкрийте Провідник → файл → права кнопка миші → Властивості → Докладно. Запишіть саме те, що бачите. Поле «Створено» на вкладці «Загальні» не обов'язково є датою фотографування.

КРОК 03 / ІНШИЙ АНАЛІЗАТОР

🔎 Перевірте EXIF у браузері

Натисніть «Аналізувати оригінал». Програма прочитає базові EXIF-поля з файлу локально. Це другий інструмент для зіставлення з Windows — сторонній онлайн-сервіс не потрібен.

Спочатку оберіть оригінальний файл.
Увага: якщо метадані не знайдено, це не означає, що фотографія підроблена. Можливо, обрано вже оброблену копію або формат, який цей аналізатор не підтримує.
КРОК 04 / TELEGRAM

📲 Надішліть фото собі

  1. Відкрийте Telegram → «Збережені повідомлення».
  2. Надішліть оригінальну фотографію як фото, не як файл/документ.
  3. Завантажте отримане фото з Telegram назад на комп'ютер.
  4. Виберіть отриману копію нижче.

КРОК 05 / ЗІСТАВЛЕННЯ

⚖️ Порівняйте результати

Завантажте обидва файли та натисніть кнопку порівняння.

SHA-256 — цифровий відбиток байтів файлу. Різні хеші означають, що вміст файлів у байтах відрізняється, але самі по собі не доводять підробку.

🧩 Контрольне запитання

Що можна довести, якщо після пересилання як фото зникли EXIF-поля, а SHA-256 змінився?

Оберіть варіант. Для кожного є окреме пояснення.
КРОК 06 / КОНТРОЛЬНИЙ ДОСЛІД

📁 А якщо надіслати як файл?

Повторіть пересилання у «Збережені повідомлення», але виберіть «Надіслати як файл». Завантажте назад і порівняйте з оригіналом.

Порівняння за SHA-256 покаже, чи збігаються байти файлів.

Якщо копія ідентична оригіналу, її SHA-256 також збігається. Якщо ні — зафіксуйте розбіжність, не роблячи поспішних висновків.

КРОК 07 / ЗВІТ
