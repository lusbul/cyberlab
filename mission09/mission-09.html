🌐 Куди пішов пакет?

Ви ввели cyberlab.example і натиснули Enter. Через секунду відкрився сайт. Що сталося за цю секунду?

🌐 Відстежити запит
МЕРЕЖЕВИЙ ІНЦИДЕНТ

Сайт виглядає правильно. Але чи туди ми потрапили?

Аналітик хотів відкрити portal.cyberlab.example, проте побачив підроблену сторінку входу. Дослідіть DNS, IP, пакети, HTTPS та відновіть маршрут події.

10:42:01  DNS → 203.0.113.77
10:42:02  CONNECT → 203.0.113.77
10:42:02  TLS established
10:42:03  HTTP encrypted
10:42:04  RESPONSE encrypted

Офіційна адреса сервера: 203.0.113.42. Усі адреси й журнали тут навчальні.

🧭 Як працює відкриття сайту

📖 DNS

Перетворює доменне ім'я на IP-адресу.

📍 IP та пакети

Адресація і доставка даних через маршрутизатори.

📩 HTTP

Запит сторінки й відповідь сервера.

🔒 HTTPS / TLS

Захищає передавання даних, але не гарантує чесності сайту.

Приклад: домен → DNS → IP → з'єднання → TLS (для HTTPS) → HTTP-запит → HTTP-відповідь.

Розслідувати

🖥️ Спробуйте на своєму ПК (необов'язково)

У Windows відкрийте командний рядок і виконайте:

nslookup example.com
tracert example.com

Зверніть увагу: IP та кількість переходів можуть відрізнятися. Це нормальна особливість мережі.
