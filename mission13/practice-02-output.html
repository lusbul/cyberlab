💬 Коли текст стає кодом

Порівняйте, як браузер обробляє текст із HTML-тегами. Навчальна демонстрація не виконує введені скрипти.

Результат у навчальному контейнері

Що робить код

result.innerHTML = userInput;

Чому це важливо?

Якщо звичайний текст вставляти через innerHTML, HTML-теги можуть змінити структуру сторінки. Для повідомлень, які мають залишатися текстом, використовуйте textContent. Для складного HTML потрібна спеціалізована контекстна обробка, а не просто видалення символів.

Демонстрація навмисно обмежена безпечними тегами й не виконує довільний HTML або JavaScript.
